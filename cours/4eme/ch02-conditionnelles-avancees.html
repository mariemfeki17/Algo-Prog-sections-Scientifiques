Structures conditionnelles avancées

⏱️ Durée estimée : 55 min

Objectifs du programme officiel

  • Maîtriser la forme généralisée et à choix multiples.
  • Utiliser Selon et match...case.
  • Argumenter le choix de la structure.

2. Cours théorique

2.1 Conditionnelle généralisée

Si Condition1 Alors
  Traitement1
Sinon Si Condition2 Alors
  Traitement2
Sinon Si Condition3 Alors
  Traitement3
[Sinon
  TraitementN]
FinSi

2.2 Conditionnelle à choix multiples : Selon

Selon <Sélecteur>
  Valeur1_1[, Valeur1_2, …] : Traitement1
  Valeur2_1, Valeur2_2 : Traitement2
  [Sinon TraitementN]
Fin Selon

N.B. : le sélecteur doit être de type scalaire.

2.3 Argumentation du choix

SituationStructure
Deux cas + alternativeSi...Sinon
Plusieurs conditions ordonnéesSi...Sinon Si...
Comparaison à des valeurs précisesSelon
Intervalle ou plage de valeursSi généralisée

2.4 Exemple — Mention au bac

ALGORITHME Mention
DEBUT
  Lire(m)
  Selon m
    [0 .. 9]   : Écrire("Ajourné")
    [10 .. 11] : Écrire("Passable")
    [12 .. 13] : Écrire("Assez bien")
    [14 .. 15] : Écrire("Bien")
    [16 .. 20] : Écrire("Très bien")
    Sinon Écrire("Moyenne invalide")
  Fin Selon
FIN

Déclaration des objets
Objet    Type / Nature
m        Réel

3. Implémentation en Python

AlgorithmiquePython
Si...Alorsif ...:
Si...Sinonif ...: ... else: ...
Si...Sinon Si...if ...: ... elif ...: ... else: ...
Selonmatch...case (Python ≥ 3.10)
 
m = float(input("Moyenne : "))
match m:
    case m if 0 <= m < 10:
        print("Ajourné")
    case m if 10 <= m < 12:
        print("Passable")
    case m if 12 <= m < 14:
        print("Assez bien")
    case m if 14 <= m < 16:
        print("Bien")
    case m if 16 <= m <= 20:
        print("Très bien")
    case _:
        print("Moyenne invalide")

4. Remarques et pièges fréquents

  • Le sélecteur de Selon doit être scalaire.
  • match...case nécessite Python ≥ 3.10.
  • Ne pas oublier le cas par défaut.
  • Utiliser case _ pour le cas par défaut en Python.
  • Argumenter le choix de la structure.

5. Exercices corrigés

Exercice 1 — Calculatrice avec Selon

Implémenter une calculatrice avec +, -, *, /, en gérant la division par zéro.

ALGORITHME Calculatrice
DEBUT
  Lire(a)
  Lire(b)
  Lire(op)
  Selon op
    '+' : Écrire(a + b)
    '-' : Écrire(a - b)
    '*' : Écrire(a * b)
    '/' : Si b ≠ 0 Alors Écrire(a / b)
          Sinon Écrire("Division par zéro")
          FinSi
    Sinon Écrire("Opérateur inconnu")
  Fin Selon
FIN

Déclaration des objets
Objet    Type / Nature
a, b     Réel
op       Caractère
a = float(input("a : "))
b = float(input("b : "))
op = input("Opérateur : ")
match op:
    case '+': print(a + b)
    case '-': print(a - b)
    case '*': print(a * b)
    case '/':
        if b != 0: print(a / b)
        else: print("Division par zéro")
    case _: print("Opérateur inconnu")

Exercice 2 — Saison selon le mois

Afficher la saison (Hiver, Printemps, Été, Automne) selon le numéro du mois.

ALGORITHME Saison
DEBUT
  Lire(m)
  Selon m
    12, 1, 2 : Écrire("Hiver")
    3, 4, 5  : Écrire("Printemps")
    6, 7, 8  : Écrire("Été")
    9, 10, 11: Écrire("Automne")
    Sinon Écrire("Mois invalide")
  Fin Selon
FIN

Déclaration des objets
Objet    Type / Nature
m        Entier
m = int(input("Mois : "))
match m:
    case 12 | 1 | 2: print("Hiver")
    case 3 | 4 | 5: print("Printemps")
    case 6 | 7 | 8: print("Été")
    case 9 | 10 | 11: print("Automne")
    case _: print("Mois invalide")
