Interface graphique avec Qt Designer

⏱️ Durée estimée : 70 min

Objectifs du programme officiel

  • Découvrir l'interface graphique à partir d'une application existante.
  • Concevoir et utiliser une GUI avec Qt Designer.
  • Utiliser le glisser-déposer et les méthodes : .text, .setText, .clear, .show, .clicked.

2. Cours théorique

2.1 Principes d'une interface graphique

Une interface graphique (GUI) permet à l'utilisateur d'interagir avec un programme via des objets visuels : boutons, champs de saisie, étiquettes, etc.

2.2 Concevoir avec Qt Designer

Qt Designer permet de :

  • Glisser–Déposer les objets graphiques sur une fenêtre.
  • Configurer leurs propriétés (nom, texte, taille).
  • Sauvegarder l'interface dans un fichier .ui.

2.3 Objets graphiques courants

ObjetRôle
QLabelÉtiquette (texte non modifiable)
QLineEditChamp de saisie
QPushButtonBouton
QTextEditZone de texte multilignes

2.4 Méthodes autorisées

La convention limite l'usage à ces méthodes :

  • .text : lire le texte d'un objet.
  • .setText(...) : modifier le texte.
  • .clear() : effacer le contenu.
  • .show() : afficher un objet.
  • .clicked : signal de clic (utilisé pour connecter).

2.5 Exemple — Calculatrice simple

Interface avec deux champs a, b, un bouton btnSomme et un label lblResultat.

from PyQt5.QtWidgets import QApplication, QMainWindow
from PyQt5.uic import loadUi
import sys

class Fenetre(QMainWindow):
    def __init__(self):
        super().__init__()
        loadUi("calculatrice.ui", self)
        self.btnSomme.clicked.connect(self.calculer)

    def calculer(self):
        a = float(self.txtA.text)
        b = float(self.txtB.text)
        s = a + b
        self.lblResultat.setText("Somme = " + str(s))

app = QApplication(sys.argv)
f = Fenetre()
f.show()
app.exec_()

3. Remarques et pièges fréquents

  • L'usage de la GUI doit améliorer l'ergonomie, pas être un objet principal d'apprentissage.
  • Se limiter aux méthodes listées : .text, .setText, .clear, .show, .clicked.
  • Traiter des problèmes avec une seule interface.
  • Installer Qt Designer et les bibliothèques nécessaires.
  • Convertir les textes (.text) en nombres si nécessaire.

4. Exercices corrigés

Exercice 1 — Calculatrice simple

Concevoir une interface avec deux champs et un bouton « Somme », afficher le résultat dans un label.

from PyQt5.QtWidgets import QApplication, QMainWindow
from PyQt5.uic import loadUi
import sys

class Fenetre(QMainWindow):
    def __init__(self):
        super().__init__()

    def calculer(self):
        a = float(self.txtA.text)
        b = float(self.txtB.text)

app = QApplication(sys.argv)
f = Fenetre()
f.show()
app.exec_()

Exercice 2 — Bouton Effacer

Ajouter un bouton « Effacer » qui vide les champs et le label.

self.btnEffacer.clicked.connect(self.effacer)

def effacer(self):
    self.txtA.clear()
    self.txtB.clear()
    self.lblResultat.clear()
