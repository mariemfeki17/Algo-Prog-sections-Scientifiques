Les fichiers (données et textes)

from pickle import load, dump

# Écriture
F = open('donnees.dat', 'wb')
dump(42, F)
dump("Bonjour", F)
F.close()

# Lecture
F = open('donnees.dat', 'rb')
fini = False
while not fini:
    try:
        x = load(F)
        print(x)
    except:
        fini = True
F.close()

3.2 Fichier texte

# Écriture
F = open('notes.txt', 'w')
F.write("Ali\n")
F.write("Sami\n")
F.close()

# Lecture ligne par ligne
F = open('notes.txt', 'r')
ch = F.readline()
while ch != "":
    print(ch.strip())
    ch = F.readline()
F.close()

Fin de fichier texte

La fin d'un fichier texte est détectée lorsque readline() retourne une chaîne vide.

4. Remarques et pièges fréquents

  • Toujours close() un fichier après usage.
  • Modes : rb/wb/ab pour données, r/w/a pour textes.
  • readline() retourne "" à la fin (chaîne vide).
  • Utiliser try/except pour la lecture pickle.
  • Ne pas utiliser de fonctions non listées dans la convention.

5. Exercices corrigés

Exercice 1 — Écrire puis lire un fichier texte

Écrire 3 noms dans un fichier, puis les lire et les afficher.

# Écriture
F = open('noms.txt', 'w')
for i in range(3):
    nom = input("Nom : ")
    F.write(nom + "\n")
F.close()

# Lecture
F = open('noms.txt', 'r')
ch = F.readline()
while ch != "":
    print(ch.strip())
    ch = F.readline()
F.close()

Exercice 2 — Fichier de données

Sauvegarder et relire une liste de 5 entiers avec pickle.

from pickle import dump, load

F = open('entiers.dat', 'wb')
for i in range(5):
    n = int(input("n : "))
    dump(n, F)
F.close()

F = open('entiers.dat', 'rb')
fini = False
while not fini:
    try:
        x = load(F)
        print(x)
    except:
        fini = True
F.close()
