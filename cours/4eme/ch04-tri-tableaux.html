2. Rappels

En 3ème, nous avons vu le tri à bulles. En 4ème, on étudie deux autres méthodes : le tri par sélection et le tri par insertion.

3. Cours théorique

3.1 Tri par sélection

Principe : à chaque étape, on cherche le plus petit élément à partir de la position i et on l'échange avec T[i].

Procédure TriSelection (@T : Tableau de 100 Entier, n : Entier)
DEBUT
  Pour i de 0 à n - 2 Faire
    min ← i
    Pour j de i + 1 à n - 1 Faire
      Si T[j] < T[min] Alors
        min ← j
      FinSi
    Fin Pour
    Si min ≠ i Alors
      aux ← T[i]
      T[i] ← T[min]
      T[min] ← aux
    FinSi
  Fin Pour
FIN

3.2 Tri par insertion

Principe : insérer chaque élément T[i] à sa place dans la partie déjà triée T[0..i-1].

Procédure TriInsertion (@T : Tableau de 100 Entier, n : Entier)
DEBUT
  Pour i de 1 à n - 1 Faire
    cle ← T[i]
    j ← i - 1
    Tant que (j ≥ 0) Et (T[j] > cle) Faire
      T[j + 1] ← T[j]
      j ← j - 1
    Fin Tant que
    T[j + 1] ← cle
  Fin Pour
FIN

3.3 Comparaison

CritèreSélectionInsertion
ComplexitéO(n²)O(n²)
ÉchangesPeuBeaucoup
Adapté siTableau presque triéPetit tableau

4. Implémentation en Python

def tri_selection(T, n):
    for i in range(n - 1):
        mini = i
        for j in range(i + 1, n):
            if T[j] < T[mini]:
                mini = j
        if mini != i:
            T[i], T[mini] = T[mini], T[i]

def tri_insertion(T, n):
    for i in range(1, n):
        cle = T[i]
        j = i - 1
        while j >= 0 and T[j] > cle:
            T[j + 1] = T[j]
            j = j - 1
        T[j + 1] = cle

5. Remarques et pièges fréquents

  • Attention aux bornes : n - 1, i + 1.
  • Tri par insertion : condition j ≥ 0 indispensable.
  • Utiliser une variable temporaire pour l'échange.
  • Pas de break.

6. Exercices corrigés

Exercice 1 — Tri par sélection complet

Trier un tableau T de n entiers par sélection puis l'afficher.

from numpy import array

def tri_selection(T, n):
    for i in range(n - 1):
        mini = i
        for j in range(i + 1, n):
            if T[j] < T[mini]:
                mini = j
        if mini != i:
            T[i], T[mini] = T[mini], T[i]

n = int(input("Taille : "))
T = array([0] * n)
for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))
tri_selection(T, n)
for i in range(n):
    print(T[i])
