3. Cours théorique

3.1 Décomposition en sous-problèmes

Méthode :

  1. Analyser l'énoncé et identifier les tâches.
  2. Regrouper les tâches liées en modules.
  3. Définir l'entête de chaque module (paramètres, type de retour).
  4. Écrire chaque module séparément.
  5. Tester chaque module.
  6. Assembler le programme principal.

3.2 Éléments d'un module

ÉlémentDescription
EntêteNom + paramètres + type de retour
ParamètresValeurs transmises (par valeur ou référence)
RésultatUn seul résultat simple (fonction uniquement)
TypeType du résultat
PortéeLocale ou globale
AppelUtilisation du module

3.3 Exemple — Statistiques sur un tableau

Décomposer le calcul de la moyenne et du maximum d'un tableau :

Fonction SommeTab (T : Tableau de 100 Entier, n : Entier) : Entier
DEBUT
  s ← 0
  Pour i de 0 à n - 1 Faire
    s ← s + T[i]
  Fin Pour
  Retourner s
FIN

Fonction MaximumTab (T : Tableau de 100 Entier, n : Entier) : Entier
DEBUT
  max ← T[0]
  Pour i de 1 à n - 1 Faire
    Si T[i] > max Alors
      max ← T[i]
    FinSi
  Fin Pour
  Retourner max
FIN

ALGORITHME ProgrammePrincipal
DEBUT
  Lire(n)
  Pour i de 0 à n - 1 Faire
    Lire(T[i])
  Fin Pour
  m ← SommeTab(T, n) / n
  Écrire("Moyenne = ", m)
  Écrire("Maximum = ", MaximumTab(T, n))
FIN

Déclaration des objets
Objet    Type / Nature
T        Tableau de 100 Entier
n, i     Entier
m        Réel

4. Implémentation en Python

from numpy import array

def somme_tab(T, n):
    s = 0
    for i in range(n):
        s = s + T[i]
    return s

def maximum_tab(T, n):
    maxi = T[0]
    for i in range(1, n):
        if T[i] > maxi:
            maxi = T[i]
    return maxi

n = int(input("Taille : "))
T = array([0] * n)
for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))
print("Moyenne =", somme_tab(T, n) / n)
print("Maximum =", maximum_tab(T, n))

Bonnes pratiques

  • Noms significatifs.
  • Commenter chaque module.
  • Un module = une seule responsabilité.
  • Paramètres explicites (éviter les globales).

5. Remarques et pièges fréquents

  • Une fonction retourne un seul résultat simple.
  • Ne pas oublier return.
  • Tableau passé par référence en Python.
  • Éviter les variables globales.
  • Tester chaque module indépendamment.

6. Exercices corrigés

Exercice 1 — Moyenne d'un tableau

Écrire une fonction qui calcule la moyenne des éléments d'un tableau T de n réels.

Fonction Moyenne (T : Tableau de 100 Réel, n : Entier) : Réel
DEBUT
  s ← 0
  Pour i de 0 à n - 1 Faire
    s ← s + T[i]
  Fin Pour
  Retourner s / n
FIN
def moyenne(T, n):
    s = 0
    for i in range(n):
        s = s + T[i]
    return s / n

Exercice 2 — Compter les pairs

Écrire une fonction qui retourne le nombre d'éléments pairs d'un tableau T de n entiers.

Fonction NbPairs (T : Tableau de 100 Entier, n : Entier) : Entier
DEBUT
  c ← 0
  Pour i de 0 à n - 1 Faire
    Si T[i] Mod 2 = 0 Alors
      c ← c + 1
    FinSi
  Fin Pour
  Retourner c
FIN
def nb_pairs(T, n):
    c = 0
    for i in range(n):
        if T[i] % 2 == 0:
            c = c + 1
    return c
