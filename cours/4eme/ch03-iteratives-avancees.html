Structures itératives avancées

⏱️ Durée estimée : 55 min

Objectifs du programme officiel

  • Choisir entre Pour, Tant Que, Répéter selon le problème.
  • Optimiser les boucles et éviter les pièges.
  • Ne jamais utiliser break.

2. Cours théorique

2.1 Rappel des trois structures

  T
Fin Pour

  T
Fin Tant que

  T

2.2 Choix argumenté

SituationStructure
Nombre d'itérations connuPour
Condition d'arrêt testée avantTant Que
Au moins une exécution garantieRépéter
Parcours d'un tableauPour
Recherche avec arrêtTant Que

2.3 Optimisation

  • Éviter les calculs redondants dans la condition.
  • Préférer Pour quand le nombre d'itérations est connu.
  • Ne jamais modifier le compteur d'un Pour dans le traitement.
  • Garantir la terminaison : la condition doit évoluer.

2.4 Exemple — Recherche dans un tableau

ALGORITHME Recherche
DEBUT
  Lire(n)
  Lire(x)
  pos ← -1
  i ← 0
  Tant que (i < n) Et (pos = -1) Faire
    Si T[i] = x Alors
      pos ← i
    FinSi
    i ← i + 1
  Fin Tant que
  Écrire("Position = ", pos)
FIN

Déclaration des objets
Objet    Type / Nature
T        Tableau de 100 Entier
n, i, x, pos  Entier

3. Implémentation en Python

AlgorithmiquePython
Pour i de D à Ffor i in range(D, F+1):
Tant que C Fairewhile C:
Répéter...Jusqu'à Cwhile not C: ...
 
from numpy import array
n = int(input("Taille : "))
T = array([0] * n)
for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))
x = int(input("x : "))
pos = -1
i = 0
while i < n and pos == -1:
    if T[i] == x:
        pos = i
    i = i + 1
print("Position =", pos)

Interdit : break

La convention d'implémentation interdit break dans toutes les boucles.

4. Remarques et pièges fréquents

  • Boucle infinie si la condition ne change pas.
  • Ne pas modifier le compteur d'un Pour.
  • Pas de break.
  • Vérifier la terminaison avant d'écrire.

5. Exercices corrigés

Exercice 1 — Nombre de chiffres

Compter le nombre de chiffres d'un entier n avec Tant Que.

ALGORITHME NbChiffres
DEBUT
  Lire(n)
  c ← 0
  Tant que n > 0 Faire
    c ← c + 1
    n ← n Div 10
  Fin Tant que
  Écrire("Nombre de chiffres = ", c)
FIN

Déclaration des objets
Objet    Type / Nature
n, c     Entier
n = int(input("n : "))
c = 0
while n > 0:
    c = c + 1
    n = n // 10
print("Nombre de chiffres =", c)

Exercice 2 — Inverser un entier

Inverser les chiffres d'un entier n (ex : 123 → 321).

ALGORITHME Inverse
DEBUT
  Lire(n)
  inv ← 0
  Tant que n > 0 Faire
    inv ← inv * 10 + (n Mod 10)
    n ← n Div 10
  Fin Tant que
  Écrire("Inverse = ", inv)
FIN

Déclaration des objets
Objet    Type / Nature
n, inv   Entier
n = int(input("n : "))
inv = 0
while n > 0:
    inv = inv * 10 + (n % 10)
    n = n // 10
print("Inverse =", inv)
