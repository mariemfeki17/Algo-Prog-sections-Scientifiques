3. Nouveautés de la 4ème année

  • Conditionnelles généralisées et à choix multiples (Selon, match...case).
  • Tri par sélection et tri par insertion.
  • Décomposition en sous-problèmes.
  • Fichiers (textes et données).
  • Interface graphique avec Qt Designer.
  • Programmation événementielle.

3.1 Bonnes pratiques

  • Noms significatifs.
  • Indentation rigoureuse (4 espaces).
  • Commentaires utiles.
  • Pas de break.
  • Pas de print(T) pour un tableau.
  • N'utiliser que les fonctions listées dans la convention d'implémentation.

4. Exercices de révision

Exercice 1 — Révision des modules

Écrire une fonction qui retourne la somme des éléments d'un tableau T de n entiers.

Fonction SommeTab (T : Tableau de 100 Entier, n : Entier) : Entier
DEBUT
  s ← 0
  Pour i de 0 à n - 1 Faire
    s ← s + T[i]
  Fin Pour
  Retourner s
FIN
def somme_tab(T, n):
    s = 0
    for i in range(n):
        s = s + T[i]
    return s

Exercice 2 — Révision des itératives

Calculer la somme des n premiers entiers avec Tant Que.

ALGORITHME SommeN
DEBUT
  Lire(n)
  s ← 0
  i ← 1
  Tant que i ≤ n Faire
    s ← s + i
    i ← i + 1
  Fin Tant que
  Écrire("Somme = ", s)
FIN

Déclaration des objets
Objet    Type / Nature
n, i, s  Entier
n = int(input("n : "))
s = 0
i = 1
while i <= n:
    s = s + i
    i = i + 1
print("Somme =", s)
