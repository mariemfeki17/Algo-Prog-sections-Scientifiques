2. Cours théorique

2.1 Principe de la programmation événementielle

Définition

La programmation événementielle consiste à réagir à des événements (clic, saisie, etc.) déclenchés par l'utilisateur. Chaque événement est associé à une fonction (appelée callback ou gestionnaire).

2.2 Connexion d'un événement

En Qt, on utilise la méthode .clicked.connect(fonction) pour relier un bouton à une action.

self.btnValider.clicked.connect(self.valider)

2.3 Exemple complet — Calculatrice

from PyQt5.QtWidgets import QApplication, QMainWindow
from PyQt5.uic import loadUi
import sys

class Fenetre(QMainWindow):
    def __init__(self):
        super().__init__()
        loadUi("calculatrice.ui", self)
        self.btnSomme.clicked.connect(self.calculer)
        self.btnEffacer.clicked.connect(self.effacer)

    def calculer(self):
        a = float(self.txtA.text)
        b = float(self.txtB.text)
        s = a + b
        self.lblResultat.setText("Somme = " + str(s))

    def effacer(self):
        self.txtA.clear()
        self.txtB.clear()
        self.lblResultat.clear()

app = QApplication(sys.argv)
f = Fenetre()
f.show()
app.exec_()

2.4 Améliorer l'ergonomie

  • Réinitialiser les champs après chaque opération.
  • Vérifier les saisies (try/except).
  • Afficher des messages d'erreur clairs.

3. Remarques et pièges fréquents

  • Se limiter aux méthodes listées dans la convention.
  • La GUI doit rester un moyen, pas un objet principal d'apprentissage.
  • Convertir les .text en nombres avant calcul.
  • Vérifier les erreurs de saisie (try/except).

4. Exercices corrigés

Exercice 1 — Calculatrice avec vérification

Ajouter un contrôle de saisie avec try/except.

def calculer(self):
    try:
        a = float(self.txtA.text)
        b = float(self.txtB.text)
        self.lblResultat.setText("Somme = " + str(a + b))
    except:
        self.lblResultat.setText("Saisie invalide")

Exercice 2 — Bouton Effacer

Ajouter un bouton "Effacer" qui vide tous les champs.

def effacer(self):
    self.txtA.clear()
    self.txtB.clear()
    self.lblResultat.clear()
