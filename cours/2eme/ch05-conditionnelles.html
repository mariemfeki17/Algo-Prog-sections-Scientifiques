2.5 Exemple complet

Énoncé : déterminer si un entier est pair ou impair.

ALGORITHME Parite
DEBUT
  Lire(n)
  Si n Mod 2 = 0 Alors
    Écrire("Pair")
  Sinon
    Écrire("Impair")
  FinSi
FIN

Déclaration des objets
Objet    Type / Nature
n        Entier

3. Implémentation en Python

AlgorithmiquePython

Si...Sinon...FinSiif ...: ... else: ...
Et / Ou / Nonand / or / not
= / ≠== / !=
 
n = int(input("Entier : "))
if n % 2 == 0:
    print("Pair")
else:
    print("Impair")

4. Remarques et pièges fréquents

  • En Python, l'égalité s'écrit == (double égal).
  • Ne pas oublier les : après if et else.
  • Respecter l'indentation du bloc.
  • Ne pas confondre = (affectation) et == (comparaison).

5. Exercices corrigés

Exercice 1 — Maximum de deux nombres

Déterminer le maximum de deux entiers a et b.

ALGORITHME Maximum
DEBUT
  Lire(a)
  Lire(b)
  Si a > b Alors
    Écrire("Max = ", a)
  Sinon
    Écrire("Max = ", b)
  FinSi
FIN

Déclaration des objets
Objet    Type / Nature
a        Entier
b        Entier
a = int(input("a : "))
b = int(input("b : "))
if a > b:
    print("Max =", a)
else:
    print("Max =", b)

Exercice 2 — Mention au bac

À partir d'une moyenne, afficher la mention (Passable, Assez bien, Bien, Très bien).

ALGORITHME Mention
DEBUT
  Lire(m)
  Si m < 10 Alors
    Écrire("Ajourné")
  Sinon Si m < 12 Alors
    Écrire("Passable")
  Sinon Si m < 14 Alors
    Écrire("Assez bien")
  Sinon Si m < 16 Alors
    Écrire("Bien")
  Sinon
    Écrire("Très bien")
  FinSi
FIN

Déclaration des objets
Objet    Type / Nature
m        Réel
m = float(input("Moyenne : "))
if m < 10:
    print("Ajourné")
elif m < 12:
    print("Passable")
elif m < 14:
    print("Assez bien")
elif m < 16:
    print("Bien")
else:
    print("Très bien")
