3. Exercices corrigés

Exercice 1 — Programme complet

Écrire un programme qui demande le nom, l'âge et la moyenne, puis affiche un message personnalisé.

nom = input("Nom : ")
age = int(input("Âge : "))
moyenne = float(input("Moyenne : "))
print("Bonjour", nom, "!")
print("Vous avez", age, "ans et une moyenne de", moyenne)

Exercice 2 — Détection d'erreur

Corriger le programme suivant :

a = input("a : ")
b = input("b : ")
print(a + b)
a = int(input("a : "))
b = int(input("b : "))
print(a + b)

Erreur : input() renvoie une chaîne ; sans conversion, a + b concatène les chaînes.
