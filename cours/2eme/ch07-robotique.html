2ème année Chapitre 07

Initiation à la robotique

⏱️ Durée estimée : 55 min

Objectifs du programme officiel

  • Définir la robotique et identifier ses domaines d'application.
  • Connaître les interfaces d'un objet à connecter.
  • Programmer une LED et un feu de carrefour (Micro-Python / Arduino).

2. Cours théorique

2.1 Définition de la robotique

Définition

La robotique est la science qui étudie la conception, la construction et la programmation des robots. Un robot est une machine programmable capable d'exécuter des tâches de manière autonome ou semi-autonome.

2.2 Domaines d'application

  • Industrie : chaînes de montage, soudure, peinture.
  • Médecine : chirurgie assistée, prothèses.
  • Agriculture : drones, robots de récolte.
  • Domestique : aspirateurs autonomes.
  • Espace : rovers d'exploration.
  • Éducation : apprentissage du code.

2.3 Piloter un objet connecté

Pour piloter un objet connecté, il faut :

  1. Connaître les interfaces de l'objet (ports, broches).
  2. Savoir connecter l'objet à l'ordinateur (USB, Bluetooth, Wi-Fi).
  3. Programmer l'objet pour réaliser des tâches.

2.4 Exemple : faire clignoter une LED

En Micro-Python (carte type micro:bit ou Arduino) :

from microbit import *
while True:
    pin0.write_digital(1)  # LED allumée
    sleep(500)
    pin0.write_digital(0)  # LED éteinte
    sleep(500)

2.5 Exemple : feu de carrefour

from microbit import *
while True:
    # Rouge
    pin0.write_digital(1)
    pin1.write_digital(0)
    pin2.write_digital(0)
    sleep(3000)
    # Orange
    pin0.write_digital(0)
    pin1.write_digital(1)
    pin2.write_digital(0)
    sleep(1000)
    # Vert
    pin0.write_digital(0)
    pin1.write_digital(0)
    pin2.write_digital(1)
    sleep(3000)

3. Remarques

  • L'apprenant n'est pas appelé à développer une application de commande complète.
  • Utiliser Micro-Python / Arduino pour programmer la carte.
  • Activités types : LED clignotante, feu de carrefour.
  • S'appuyer sur des vidéos, ressources numériques et études de cas.

4. Exercices corrigés

Exercice 1 — LED clignotante lente

Écrire un programme qui fait clignoter une LED avec une période de 2 secondes.

from microbit import *
while True:
    pin0.write_digital(1)
    sleep(1000)
    pin0.write_digital(0)
    sleep(1000)

Exercice 2 — Feu de carrefour simplifié

Écrire un programme qui alterne rouge (3s), orange (1s), vert (3s).

from microbit import *
while True:
    pin0.write_digital(1); pin1.write_digital(0); pin2.write_digital(0)
    sleep(3000)
    pin0.write_digital(0); pin1.write_digital(1); pin2.write_digital(0)
    sleep(1000)
    pin0.write_digital(0); pin1.write_digital(0); pin2.write_digital(1)
    sleep(3000)
