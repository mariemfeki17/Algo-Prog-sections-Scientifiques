La structure répétitive Pour

⏱️ Durée estimée : 50 min

Objectifs du programme officiel

  • Écrire une boucle Pour.
  • Utiliser un compteur.
  • Implémenter for...in range() en Python.

2. Cours théorique

2.1 Structure itérative complète

Définition

La structure Pour répète un traitement un nombre connu de fois, en utilisant un compteur.

Pour Compteur de Début à Fin [Pas = valeur_pas] Faire
  Traitement
Fin Pour

Remarques :

  • Le pas peut être positif ou négatif ; par défaut il vaut 1.
  • Éviter de modifier la valeur du compteur dans le traitement.

2.2 Exemple : afficher les entiers de 1 à 5

ALGORITHME Compteur
DEBUT
  Pour i de 1 à 5 Faire
    Écrire(i)
  Fin Pour
FIN

Déclaration des objets
Objet    Type / Nature
i        Entier

2.3 Exemple : somme des n premiers entiers

ALGORITHME SommeN
DEBUT
  Lire(n)
  s ← 0
  Pour i de 1 à n Faire
    s ← s + i
  Fin Pour
  Écrire("Somme = ", s)
FIN

Déclaration des objets
Objet    Type / Nature
n        Entier
i        Entier
s        Entier

3. Implémentation en Python

AlgorithmiquePython
Pour i de D à F Fairefor i in range(D, F+1):
Pour i de D à F Pas = P Fairefor i in range(D, F+1, P):

Attention à range()

Dans range(D, F+1), la valeur finale F est incluse grâce au +1. Sans le +1, elle serait exclue.

n = int(input("n : "))
s = 0
for i in range(1, n + 1):
    s = s + i
print("Somme =", s)

Interdit : break

La convention d'implémentation interdit l'utilisation de break pour forcer l'arrêt d'une boucle.

4. Remarques et pièges fréquents

  • Ne pas oublier le +1 dans range pour inclure la borne finale.
  • Initialiser l'accumulateur avant la boucle (ex. s ← 0).
  • Ne jamais modifier le compteur dans le corps de la boucle.
  • Pas de break (interdit par la convention).
