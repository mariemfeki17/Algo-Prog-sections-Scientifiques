2. Cours théorique

2.1 L'opération d'entrée : Lire

Définition

Lire(Objet) permet de saisir une valeur au clavier et de la stocker dans l'objet.

Lire(a)

2.2 L'opération de sortie : Écrire / Écrire_nl

Définition

Écrire("Message", Objet, Expression) affiche un message et/ou la valeur d'un objet. Écrire_nl ajoute un retour à la ligne.

Écrire("La somme est : ", s)
Écrire_nl("Bonjour")

2.3 L'affectation

Définition

Objet ← Expression : l'objet reçoit la valeur de l'expression.

s ← a + b
moyenne ← (n1 + n2 + n3) / 3

2.4 Exemple complet

ALGORITHME Moyenne
DEBUT
  Lire(n1)
  Lire(n2)
  Lire(n3)
  m ← (n1 + n2 + n3) / 3
  Écrire("Moyenne = ", m)
FIN

Déclaration des objets
Objet        Type / Nature
n1, n2, n3   Réel
m            Réel

3. Implémentation en Python

AlgorithmiquePython
Lire(Objet)Objet = input() ou Objet = int(input())
Écrire("…", x)print("…", x)
Écrire_nl("…", x)print("…", x, "\n")
Objet ← ExpressionObjet = Expression
 
n1 = float(input("Note 1 : "))
n2 = float(input("Note 2 : "))
n3 = float(input("Note 3 : "))
m = (n1 + n2 + n3) / 3
print("Moyenne =", m)

Remarques importantes

  • input() retourne une chaîne → convertir avec int() ou float().
  • "\n" ajoute un retour à la ligne.
  • Interdit : print(T) pour afficher un tableau → afficher élément par élément.

4. Remarques et pièges fréquents

  • Ne pas oublier de convertir après input().
  • Le message dans Écrire est entre guillemets.
  • Ne pas confondre Écrire et Écrire_nl.
  • L'affectation utilise ←, pas =, en algorithmique.

5. Exercices corrigés

Exercice 1 — Conversion Celsius → Fahrenheit

Saisir une température en Celsius et afficher sa conversion en Fahrenheit : F = C × 9/5 + 32.

ALGORITHME Conversion
DEBUT
  Lire(C)
  F ← C * 9 / 5 + 32
  Écrire("F = ", F)
FIN

Déclaration des objets
Objet    Type / Nature
C        Réel
F        Réel
C = float(input("Celsius : "))
F = C * 9 / 5 + 32
print("F =", F)
