2. Rappels

Dans les chapitres précédents, nous avons vu qu'un objet est une zone mémoire nommée. Chaque objet possède un type qui détermine la nature de la valeur qu'il peut contenir.

3. Cours théorique

3.1 Les cinq types simples

Définition

Un type de données définit l'ensemble des valeurs qu'un objet peut prendre ainsi que les opérations applicables.

TypeDescriptionExemples
EntierNombres sans partie décimale0, 5, -12, 2024
RéelNombres avec partie décimale3.14, -0.5, 2.0
CaractèreUn seul symbole entre apostrophes'A', 'z', '5', '@'
BooléenVrai ou FauxVrai, Faux
ChaîneSuite de caractères entre guillemets"Bonjour", "Info"

3.3 Opérations sur les types

  • Entier / Réel : +, -, *, /, Div, Mod
  • Caractère : comparaison, Ord, Chr
  • Booléen : Non, Et, Ou
  • Chaîne : concaténation (+), Long, Pos, Sous_chaine, Majus…

5. Remarques et pièges fréquents

  • input() renvoie toujours une chaîne → convertir.
  • Un caractère en algorithmique s'écrit entre apostrophes : 'A'.
  • Une chaîne s'écrit entre guillemets : "Bonjour".
  • Attention à la division : / donne un réel, Div donne un entier.
