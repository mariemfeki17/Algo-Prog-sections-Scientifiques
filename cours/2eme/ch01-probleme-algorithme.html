2. Définitions et rappels

Qu'est-ce qu'un problème ?

Un problème est une situation pour laquelle on cherche une solution. En informatique, résoudre un problème consiste à transformer des entrées en sorties grâce à une suite de traitements.

Qu'est-ce qu'un algorithme ?

Un algorithme est une suite finie et ordonnée d'instructions permettant de résoudre un problème. Il est indépendant de tout langage de programmation.

3. Cours théorique

3.1 Les étapes de résolution d'un problème

  1. Analyser l'énoncé : comprendre ce qui est demandé.
  2. Dégager les entrées : les données fournies.
  3. Dégager les sorties : le résultat attendu.
  4. Déterminer les traitements : les étapes intermédiaires.
  5. Écrire l'algorithme selon la convention officielle.

3.2 Forme générale d'un algorithme

Selon la Convention algorithmique 2024, un algorithme s'écrit :

ALGORITHME Nom_algorithme
DEBUT
  Traitements
FIN

La déclaration des objets se fait juste après le titre :

ALGORITHME Nom_algorithme
DEBUT
  Traitements
FIN

Déclaration des objets
Objet          Type / Nature
Nom_objet      Type_objet

3.3 Exemple complet

Énoncé : Calculer la somme de deux entiers saisis par l'utilisateur.

Entrées : deux entiers a et b.

Sorties : la somme s.

Traitements : s ← a + b.

ALGORITHME Somme
DEBUT
  Lire(a)
  Lire(b)
  s ← a + b
  Écrire("La somme est : ", s)
FIN

Déclaration des objets
Objet    Type / Nature
a        Entier
b        Entier
s        Entier

4. Implémentation en Python

Conformément à la Convention d'implémentation 2024-2025, on utilise input() pour la saisie, print() pour l'affichage, et = pour l'affectation. Attention : input() retourne toujours une chaîne ; il faut convertir avec int() ou float(). 

# Algorithme Somme — implémentation Python
a = int(input("Donner le premier entier : "))
b = int(input("Donner le deuxième entier : "))
s = a + b
print("La somme est :", s)

5. Remarques et pièges fréquents

  • Ne pas oublier de déclarer les objets dans l'algorithme.
  • Respecter l'indentation (obligatoire selon la convention).
  • En Python, input() renvoie une chaîne : convertir si besoin.
  • Utiliser une nomenclature significative pour les objets.
  • Ne jamais utiliser break dans une boucle (interdit par la convention).

6. Exercices corrigés

Exercice 1 — Aire d'un rectangle

Écrire un algorithme qui calcule et affiche l'aire d'un rectangle à partir de sa longueur et de sa largeur.

ALGORITHME AireRectangle
DEBUT
  Lire(L)
  Lire(l)
  A ← L * l
  Écrire("Aire = ", A)
FIN

Déclaration des objets
Objet    Type / Nature
L        Réel
l        Réel
A        Réel
L = float(input("Longueur : "))
l = float(input("Largeur : "))
A = L * l
print("Aire =", A)

Exercice 2 — Moyenne de trois notes

Écrire un algorithme qui calcule la moyenne de trois notes saisies.

ALGORITHME Moyenne
DEBUT
  Lire(n1)
  Lire(n2)
  Lire(n3)
  m ← (n1 + n2 + n3) / 3
  Écrire("Moyenne = ", m)
FIN

Déclaration des objets
Objet    Type / Nature
n1, n2, n3  Réel
m           Réel
n1 = float(input("Note 1 : "))
n2 = float(input("Note 2 : "))
n3 = float(input("Note 3 : "))
m = (n1 + n2 + n3) / 3
print("Moyenne =", m)
