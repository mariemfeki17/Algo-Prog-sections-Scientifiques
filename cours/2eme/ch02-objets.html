Les objets : constantes et variables

⏱️ Durée estimée : 50 min

Objectifs du programme officiel

  • Distinguer une constante d'une variable.
  • Déclarer un objet selon la convention algorithmique.
  • Affecter une valeur à une variable et implémenter en Python.

2. Rappels du chapitre précédent

Dans le chapitre 1, nous avons vu qu'un algorithme manipule des entrées, effectue des traitements et produit des sorties. Ces entrées et sorties sont stockées dans des objets.

3. Cours théorique

3.1 Qu'est-ce qu'un objet ?

Définition

Un objet est une zone mémoire nommée dans laquelle on stocke une valeur. En algorithmique, on distingue deux catégories d'objets : les constantes et les variables.

3.2 La constante

Définition

Une constante est un objet dont la valeur ne change pas pendant l'exécution de l'algorithme. Elle est définie une seule fois.

Exemple : la valeur de π (3,14), le nombre de jours dans une semaine (7).

3.3 La variable

Définition

Une variable est un objet dont la valeur peut changer au cours de l'exécution de l'algorithme.

Exemple : la note d'un élève, le compteur d'une boucle, la somme de deux nombres.

3.4 Déclaration des objets

Selon la Convention algorithmique 2024, les objets se déclarent après le titre de l'algorithme :

ALGORITHME Nom_algorithme
DEBUT
  Traitements
FIN

Déclaration des objets
Objet          Type / Nature
Nom_objet      Type_objet

Règles :

  • La nomenclature des objets doit être significative.
  • Chaque objet a un type (entier, réel, caractère, booléen, chaîne).
  • L'écriture doit respecter l'indentation.

3.5 L'affectation

L'affectation permet de donner une valeur à une variable :

Objet ← Expression

Le symbole ← se lit « reçoit ».

3.6 Exemple complet

Énoncé : Calculer le prix TTC d'un article à partir de son prix HT et d'un taux de TVA.

Entrées : prixHT (réel), tauxTVA (réel).

Sorties : prixTTC (réel).

Traitements : prixTTC ← prixHT * (1 + tauxTVA / 100).

ALGORITHME PrixTTC
DEBUT
  Lire(prixHT)
  Lire(tauxTVA)
  prixTTC ← prixHT * (1 + tauxTVA / 100)
  Écrire("Prix TTC = ", prixTTC)
FIN

Déclaration des objets
Objet       Type / Nature
prixHT      Réel
tauxTVA     Réel
prixTTC     Réel

4. Implémentation en Python

En Python, une variable n'a pas besoin d'être déclarée : elle est créée au moment de l'affectation. Son type est défini par la valeur qui lui est attribuée. 

# Algorithme PrixTTC — implémentation Python
prixHT = float(input("Donner le prix HT : "))
tauxTVA = float(input("Donner le taux de TVA (%) : "))
prixTTC = prixHT * (1 + tauxTVA / 100)
print("Prix TTC =", prixTTC)

Correspondances algorithmique ↔ Python

AlgorithmiquePython
Objet ← ExpressionObjet = Expression
Lire(x)x = input() (avec conversion)
Écrire("…", x)print("…", x)

⚠️ Sensibilité à la casse

Python est sensible à la casse : prix, Prix et PRIX sont trois variables différentes.

5. Remarques et pièges fréquents

  • Ne pas confondre constante (valeur fixe) et variable (valeur modifiable).
  • Utiliser des noms significatifs : moyenne plutôt que m.
  • Respecter l'indentation dans la déclaration des objets.
  • En Python, ne pas oublier la conversion après input().
  • Le nom d'une variable ne peut pas commencer par un chiffre ni contenir d'espaces.

6. Exercices corrigés

Exercice 1 — Périmètre d'un cercle

Écrire un algorithme qui calcule le périmètre d'un cercle de rayon R, en utilisant la constante PI = 3.14.

ALGORITHME PerimetreCercle
DEBUT
  PI ← 3.14
  Lire(R)
  P ← 2 * PI * R
  Écrire("Périmètre = ", P)
FIN

Déclaration des objets
Objet    Type / Nature
PI       Réel (constante)
R        Réel
P        Réel
PI = 3.14
R = float(input("Rayon : "))
P = 2 * PI * R
print("Périmètre =", P)

Exercice 2 — Échange de deux variables

Écrire un algorithme qui échange les valeurs de deux variables a et b.

ALGORITHME Echange
DEBUT
  Lire(a)
  Lire(b)
  aux ← a
  a ← b
  b ← aux
  Écrire("a = ", a, " b = ", b)
FIN

Déclaration des objets
Objet    Type / Nature
a        Entier
b        Entier
aux      Entier
a = int(input("a : "))
b = int(input("b : "))
aux = a
a = b
b = aux
print("a =", a, " b =", b)

Astuce Python : on peut aussi écrire a, b = b, a.
