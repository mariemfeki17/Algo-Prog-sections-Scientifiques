2. Rappels

En 2ème, nous avons découvert la robotique : définition, domaines, pilotage d'une LED et d'un feu de carrefour simple. En 3ème, on consolide et on complexifie.

3. Consolidation

3.1 Rappel des domaines

  • Industrie : robots de soudure, chaînes de montage.
  • Médecine : robots chirurgicaux, prothèses.
  • Agriculture : drones, robots de récolte.
  • Espace : rovers, satellites.
  • Éducation : kits pédagogiques (micro:bit, Arduino).

3.2 Programmation avancée — feu de carrefour complet

Feu de carrefour avec 3 LED (rouge, orange, vert) et un cycle complet :

from microbit import *
while True:
    # Rouge : 3 s
    pin0.write_digital(1)
    pin1.write_digital(0)
    pin2.write_digital(0)
    sleep(3000)
    # Orange : 1 s
    pin0.write_digital(0)
    pin1.write_digital(1)
    pin2.write_digital(0)
    sleep(1000)
    # Vert : 3 s
    pin0.write_digital(0)
    pin1.write_digital(0)
    pin2.write_digital(1)
    sleep(3000)
    # Orange : 1 s (transition)
    pin0.write_digital(0)
    pin1.write_digital(1)
    pin2.write_digital(0)
    sleep(1000)

3.3 Utilisation des modules

On peut factoriser le code avec des fonctions :

from microbit import *

def allumer(rouge, orange, vert):
    pin0.write_digital(rouge)
    pin1.write_digital(orange)
    pin2.write_digital(vert)

while True:
    allumer(1, 0, 0); sleep(3000)  # Rouge
    allumer(0, 1, 0); sleep(1000)  # Orange
    allumer(0, 0, 1); sleep(3000)  # Vert
    allumer(0, 1, 0); sleep(1000)  # Orange

4. Remarques

  • L'apprenant n'est pas appelé à développer une application de commande complète.
  • Utiliser Micro-Python / Arduino.
  • S'appuyer sur des vidéos, ressources numériques et études de cas.
  • Factoriser le code avec des modules quand c'est possible.

5. Exercices corrigés

Exercice 1 — Chenillard

Faire clignoter 3 LED l'une après l'autre (chenillard).

from microbit import *
while True:
    pin0.write_digital(1); pin1.write_digital(0); pin2.write_digital(0)
    sleep(300)
    pin0.write_digital(0); pin1.write_digital(1); pin2.write_digital(0)
    sleep(300)
    pin0.write_digital(0); pin1.write_digital(0); pin2.write_digital(1)
    sleep(300)
