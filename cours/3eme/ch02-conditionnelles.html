Les structures conditionnelles : Si et Selon

⏱️ Durée estimée : 55 min

Objectifs du programme officiel

  • Maîtriser Si, Si...Sinon et Selon.
  • Choisir la structure adéquate selon le problème.
  • Implémenter en Python (if / elif / else / match...case).

2. Rappels du chapitre précédent

En 2ème année, nous avons vu Si...Alors et Si...Sinon. En 3ème, on ajoute la structure Selon qui permet de choisir parmi plusieurs valeurs.

3. Cours théorique

3.1 Condition simple

Si Condition Alors
  Traitement
FinSi

3.2 Condition complète

Si Condition Alors
  Traitement1
Sinon
  Traitement2
FinSi

3.3 Condition généralisée

Si Condition1 Alors
  Traitement1
Sinon Si Condition2 Alors
  Traitement2
Sinon Si Condition3 Alors
  Traitement3
[Sinon
  TraitementN]
FinSi

3.4 Condition à choix multiples : Selon

Selon <Sélecteur>
  Valeur1_1[, Valeur1_2, …] : Traitement1
  Valeur2_1, Valeur2_2 : Traitement2
  [Sinon
    TraitementN]
Fin Selon

N.B. : le sélecteur doit être de type scalaire (entier, caractère…).

3.5 Exemple complet — Jours de la semaine

ALGORITHME JourSemaine
DEBUT
  Lire(j)
  Selon j
    1, 2, 3, 4, 5 : Écrire("Jour ouvrable")
    6, 7 : Écrire("Week-end")
    Sinon Écrire("Numéro invalide")
  Fin Selon
FIN

Déclaration des objets
Objet    Type / Nature
j        Entier

4. Implémentation en Python

AlgorithmiquePython
Si...Alors...FinSiif ...:
Si...Sinon...FinSiif ...: ... else: ...
Si...Sinon Si...if ...: ... elif ...: ... else: ...
Selon...Fin Selonmatch...case (Python ≥ 3.10)
 
j = int(input("Numéro du jour : "))
match j:
    case 1 | 2 | 3 | 4 | 5:
        print("Jour ouvrable")
    case 6 | 7:
        print("Week-end")
    case _:
        print("Numéro invalide")

5. Remarques et pièges fréquents

  • Le sélecteur de Selon doit être de type scalaire.
  • En Python, match...case nécessite Python ≥ 3.10.
  • Ne pas oublier le cas par défaut (Sinon / case _).
  • Ne pas confondre = (affectation) et == (comparaison).

6. Exercices corrigés

Exercice 1 — Calculatrice avec Selon

Saisir deux réels et un opérateur (+, -, *, /), puis afficher le résultat.

ALGORITHME Calculatrice
DEBUT
  Lire(a)
  Lire(b)
  Lire(op)
  Selon op
    '+' : Écrire("Somme = ", a + b)
    '-' : Écrire("Différence = ", a - b)
    '*' : Écrire("Produit = ", a * b)
    '/' : Si b ≠ 0 Alors
            Écrire("Quotient = ", a / b)
          Sinon
            Écrire("Division par zéro impossible")
          FinSi
    Sinon Écrire("Opérateur inconnu")
  Fin Selon
FIN

Déclaration des objets
Objet    Type / Nature
a, b     Réel
op       Caractère
a = float(input("a : "))
b = float(input("b : "))
op = input("Opérateur : ")
match op:
    case '+':
        print("Somme =", a + b)
    case '-':
        print("Différence =", a - b)
    case '*':
        print("Produit =", a * b)
    case '/':
        if b != 0:
            print("Quotient =", a / b)
        else:
            print("Division par zéro impossible")
    case _:
        print("Opérateur inconnu")
