2. Rappels

Jusqu'ici, nos algorithmes étaient monolithiques. La décomposition modulaire consiste à les découper en sous-programmes (modules) réutilisables.

3. Cours théorique

3.1 Pourquoi modulariser ?

  • Lisibilité : un programme court est plus clair.
  • Réutilisabilité : un module peut être appelé plusieurs fois.
  • Maintenance : on corrige un seul endroit.
  • Testabilité : chaque module peut être testé isolément.

3.2 Déclaration d'une fonction

Fonction Nom_fonction (pf1 : type1, pf2 : type2, …, pfN : typeN) : Type_résultat

3.4 Appel

ModuleAppel

3.5 Mode de passage

  • Par valeur : la valeur est copiée.
  • Par référence : on ajoute le symbole @ avant le paramètre. La modification affecte l'objet d'origine.

3.6 Exemple complet

Énoncé : écrire une fonction qui calcule le PGCD de deux entiers par l'algorithme d'Euclide.

Fonction PGCD (a : Entier, b : Entier) : Entier
DEBUT
  Tant que b ≠ 0 Faire
    r ← a Mod b
    a ← b
    b ← r
  Fin Tant que
  Retourner a
FIN

ALGORITHME ProgrammePrincipal
DEBUT
  Lire(x)
  Lire(y)
  p ← PGCD(x, y)
  Écrire("PGCD = ", p)
FIN

Déclaration des objets
Objet    Type / Nature
x, y     Entier
p        Entier

4. Implémentation en Python

En Python, un module se définit avec le mot-clé def.

def pgcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

# Programme principal
x = int(input("x : "))
y = int(input("y : "))
p = pgcd(x, y)
print("PGCD =", p)

Portée des variables

  • Variable locale : déclarée dans un module.
  • Variable globale : précédée de global ; ne doit pas figurer parmi les paramètres.

5. Remarques et pièges fréquents

  • Une fonction retourne un seul résultat de type simple.
  • Ne pas oublier return dans une fonction.
  • En Python, les paramètres tableau/dict/fichier sont passés par référence par défaut.
  • Éviter les variables globales non nécessaires.
  • Commenter chaque module.

6. Exercices corrigés

Exercice 1 — Fonction maximum

Écrire une fonction qui retourne le maximum de deux entiers.

Fonction Maximum (a : Entier, b : Entier) : Entier
DEBUT
  Si a > b Alors
    Retourner a
  Sinon
    Retourner b
  FinSi
FIN
def maximum(a, b):
    if a > b:
        return a
    else:
        return b

print(maximum(3, 7))  # 7

Exercice 2 — Procédure d'affichage de tableau

Écrire une procédure qui affiche un tableau T de n entiers.

Procédure AfficherTab (T : Tableau de 100 Entier, n : Entier)
DEBUT
  Pour i de 0 à n - 1 Faire
    Écrire(T[i])
  Fin Pour
FIN
def afficher_tab(T, n):
    for i in range(n):
        print(T[i])

Exercice 3 — Saisie contrôlée modulaire

Écrire une fonction qui saisit un entier entre deux bornes.

Fonction SaisieTaille (bornInf : Entier, bornSup : Entier) : Entier
DEBUT
  taille ← 0
  Tant que (taille < bornInf) Ou (taille > bornSup) Faire
    Lire(taille)
  Fin Tant que
  Retourner taille
FIN
def saisie_taille(bornInf, bornSup):
    taille = 0
    while taille < bornInf or taille > bornSup:
        taille = int(input("Taille entre " + str(bornInf) + " et " + str(bornSup) + " : "))
    return taille
