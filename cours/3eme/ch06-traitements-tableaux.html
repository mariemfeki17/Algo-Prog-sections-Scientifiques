2. Cours théorique

2.1 Recherche d'un élément

Parcourir le tableau jusqu'à trouver la valeur x. On renvoie son indice ou -1 s'il n'existe pas.

Fonction Recherche (T : Tableau de 100 Entier, n : Entier, x : Entier) : Entier
DEBUT
  i ← 0
  pos ← -1
  Tant que (i < n) Et (pos = -1) Faire
    Si T[i] = x Alors
      pos ← i
    Sinon
      i ← i + 1
    FinSi
  Fin Tant que
  Retourner pos
FIN

2.2 Tri à bulles

Principe : comparer les éléments deux à deux et échanger s'ils sont mal ordonnés. À chaque passage, le plus grand « remonte » à la fin.

Procédure TriBulles (@T : Tableau de 100 Entier, n : Entier)
DEBUT
  Pour i de 1 à n - 1 Faire
    Pour j de 0 à n - i - 1 Faire
      Si T[j] > T[j + 1] Alors
        aux ← T[j]
        T[j] ← T[j + 1]
        T[j + 1] ← aux
      FinSi
    Fin Pour
  Fin Pour
FIN

3. Implémentation en Python

3.1 Recherche

def recherche(T, n, x):
    i = 0
    pos = -1
    while i < n and pos == -1:
        if T[i] == x:
            pos = i
        else:
            i = i + 1
    return pos

3.2 Tri à bulles

def tri_bulles(T, n):
    for i in range(1, n):
        for j in range(n - i):
            if T[j] > T[j + 1]:
                T[j], T[j + 1] = T[j + 1], T[j]

Remarque : en Python, le tableau est passé par référence : les modifications sont visibles à l'extérieur de la procédure.

4. Remarques et pièges fréquents

  • Indice de départ : 0.
  • Attention aux bornes des boucles imbriquées (n - i - 1).
  • Utiliser une variable temporaire pour l'échange (ou l'affectation multiple Python).
  • Pas de break.

5. Exercices corrigés

Exercice 1 — Recherche et comptage

Compter le nombre d'occurrences d'un entier x dans un tableau T de n entiers.

Fonction Compteur (T : Tableau de 100 Entier, n : Entier, x : Entier) : Entier
DEBUT
  c ← 0
  Pour i de 0 à n - 1 Faire
    Si T[i] = x Alors
      c ← c + 1
    FinSi
  Fin Pour
  Retourner c
FIN
def compteur(T, n, x):
    c = 0
    for i in range(n):
        if T[i] == x:
            c = c + 1
    return c
