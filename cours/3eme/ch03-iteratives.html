3ème année Chapitre 03

Les structures itératives : Pour, Tant Que, Répéter

⏱️ Durée estimée : 60 min

Objectifs du programme officiel

  • Distinguer les trois structures itératives.
  • Choisir la structure adéquate selon le problème.
  • Implémenter en Python (for, while).

1. Références officielles

DomainePensée computationnelle et programmation
Année3ème année secondaire
SourceAides pédagogiques 2022-2023, page 5 · Convention algorithmique 2024, p. 5

2. Rappels

En 2ème année, nous avons vu la structure Pour. En 3ème, on ajoute Tant Que et Répéter.

3. Cours théorique

3.1 Structure itérative complète : Pour

Pour Compteur de Début à Fin [Pas = valeur_pas] Faire
  Traitement
Fin Pour

Utilisée quand on connaît le nombre d'itérations à l'avance.

3.2 Structure Tant Que

Tant que Condition Faire
  Traitement
Fin Tant que

La condition est testée avant chaque itération. Le traitement peut ne jamais s'exécuter.

3.3 Structure Répéter

Répéter
  Traitement
Jusqu'à Condition

La condition est testée après chaque itération. Le traitement s'exécute au moins une fois.

3.4 Choix de la structure

SituationStructure
Nombre d'itérations connuPour
Condition d'arrêt testée avantTant Que
Au moins une exécution garantieRépéter

3.5 Exemple complet — Saisie contrôlée

Énoncé : saisir un entier n entre 1 et 100 (répéter tant que n est hors bornes).

ALGORITHME SaisieControlee
DEBUT
  Répéter
    Lire(n)
  Jusqu'à (n ≥ 1) Et (n ≤ 100)
  Écrire("n = ", n)
FIN

Déclaration des objets
Objet    Type / Nature
n        Entier

4. Implémentation en Python

AlgorithmiquePython
Pour i de D à Ffor i in range(D, F+1):
Tant que C Fairewhile C:
Répéter...Jusqu'à Cwhile not C: ... (ou boucle infinie avec test)
 
# Répéter...Jusqu'à
n = 0
while not (1 <= n <= 100):
    n = int(input("n entre 1 et 100 : "))
print("n =", n)

Interdit : break

La convention d'implémentation interdit l'utilisation de break dans les boucles.

5. Remarques et pièges fréquents

  • Ne pas oublier de faire évoluer la condition dans Tant Que / Répéter (sinon boucle infinie).
  • Dans Pour : ne pas modifier le compteur.
  • Pas de break.
  • Choisir la bonne structure selon que le nombre d'itérations est connu ou non.

6. Exercices corrigés

Exercice 1 — Somme jusqu'à 0

Saisir des entiers et calculer leur somme jusqu'à la saisie de 0.

ALGORITHME SommeZero
DEBUT
  s ← 0
  Lire(n)
  Tant que n ≠ 0 Faire
    s ← s + n
    Lire(n)
  Fin Tant que
  Écrire("Somme = ", s)
FIN

Déclaration des objets
Objet    Type / Nature
n        Entier
s        Entier
s = 0
n = int(input("n : "))
while n != 0:
    s = s + n
    n = int(input("n : "))
print("Somme =", s)
