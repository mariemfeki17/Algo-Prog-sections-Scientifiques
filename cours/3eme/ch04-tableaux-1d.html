Les tableaux à une dimension

⏱️ Durée estimée : 60 min

Objectifs du programme officiel

  • Déclarer et remplir un tableau à une dimension.
  • Parcourir et afficher un tableau.
  • Implémenter avec la bibliothèque numpy.

2. Cours théorique

2.1 Définition

Définition

Un tableau à une dimension est une structure de données qui regroupe plusieurs éléments de même type, accessibles par un indice.

2.2 Déclaration

Déclaration des objets
Objet       Type / Nature
T           Tableau de N Entier

2.3 Accès aux éléments

  • Indice du premier élément : 0.
  • Accès : T[i] avec 0 ≤ i < N.
  • Les éléments d'un tableau doivent être de même type.

2.4 Remplissage et affichage

3. Implémentation en Python (numpy)

On utilise la bibliothèque numpy pour implémenter les tableaux.

from numpy import array

# Déclaration d'un tableau de 10 entiers initialisés à 0
T = array([0] * 10)

# Déclaration d'un tableau de 10 réels initialisés à 0.0
T2 = array([0.0] * 10)

# Déclaration d'un tableau de 10 chaînes
T3 = array([str] * 10)
DéclarationExplication
T = array([5] * 10)10 entiers initialisés à 5
T = array([float()] * 10)10 réels initialisés à 0.0
T = array([str] * 10)10 chaînes
T = array([str()] * 10)10 caractères vides
T = array([''] * 10, dtype='U20')10 chaînes de 20 caractères max

3.1 Remplissage et affichage en Python

from numpy import array

n = int(input("Taille : "))
T = array([0] * n)

for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))

for i in range(n):
    print(T[i])

Attention

La convention d'implémentation interdit print(T) pour afficher un tableau. Il faut afficher élément par élément.

4. Remarques et pièges fréquents

  • Indice du premier élément : 0.
  • Tous les éléments d'un tableau sont de même type.
  • Ne pas oublier l'import from numpy import array.
  • Ne pas utiliser print(T).
  • La taille d'un tableau numpy est fixée à la création.

Exercice 2 — Maximum d'un tableau

Trouver le maximum d'un tableau T de n réels.

ALGORITHME MaximumTab
DEBUT
  Lire(n)
  Pour i de 0 à n - 1 Faire
    Lire(T[i])
  Fin Pour
  max ← T[0]
  Pour i de 1 à n - 1 Faire
    Si T[i] > max Alors
      max ← T[i]
    FinSi
  Fin Pour
  Écrire("Maximum = ", max)
FIN

Déclaration des objets
Objet    Type / Nature
T        Tableau de 100 Réel
n        Entier
i        Entier
max      Réel
from numpy import array
n = int(input("Taille : "))
T = array([0.0] * n)
for i in range(n):
    T[i] = float(input("T[" + str(i) + "] : "))
maxi = T[0]
for i in range(1, n):
    if T[i] > maxi:
        maxi = T[i]
print("Maximum =", maxi)
