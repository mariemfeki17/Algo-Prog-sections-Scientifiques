Recherche d'un élément

Fonction Recherche (T, n, x) : Entier
DEBUT
  i ← 0
  pos ← -1
  Tant que (i < n) Et (pos = -1) Faire
    Si T[i] = x Alors
      pos ← i
    Sinon
      i ← i + 1
    FinSi
  Fin Tant que
  Retourner pos
FIN

Tri à bulles

Procédure TriBulles (@T, n)
DEBUT
  Pour i de 1 à n - 1 Faire
    Pour j de 0 à n - i - 1 Faire
      Si T[j] > T[j + 1] Alors
        aux ← T[j]
        T[j] ← T[j + 1]
        T[j + 1] ← aux
      FinSi
    Fin Pour
  Fin Pour
FIN

Python — Tri à bulles

def tri_bulles(T, n):
    for i in range(1, n):
        for j in range(n - i):
            if T[j] > T[j + 1]:
                T[j], T[j + 1] = T[j + 1], T[j]

À retenir

  • Recherche : parcours + arrêt.
  • Tri à bulles : 2 boucles imbriquées.
  • Échange : variable temporaire ou affectation multiple.
  • numpy : passage par référence.
