Chapitre 02

Conditionnelles : Si et Selon

Condition simple et complète

Si C Alors
  T1
FinSi

Si C Alors
  T1
Sinon
  T2
FinSi

Condition généralisée

Si C1 Alors
  T1
Sinon Si C2 Alors
  T2
Sinon
  T3
FinSi

Selon

Selon <Sélecteur>
  V1, V2 : T1
  V3 : T2
  Sinon T3
Fin Selon

Sélecteur : type scalaire.

Exemple — Calculatrice

a = float(input("a : "))
b = float(input("b : "))
op = input("Opérateur : ")
match op:
    case '+': print("Somme =", a + b)
    case '-': print("Différence =", a - b)
    case '*': print("Produit =", a * b)
    case '/':
        if b != 0: print(a / b)
        else: print("Division par zéro")
    case _: print("Opérateur inconnu")

Exercice

Afficher la mention selon une moyenne.

m = float(input("Moyenne : "))
match m:
    case m if m < 10: print("Ajourné")
    case m if m < 12: print("Passable")
    case m if m < 14: print("Assez bien")
    case m if m < 16: print("Bien")
    case _: print("Très bien")

À retenir

  • Si / Si...Sinon / Si...Sinon Si.
  • Selon : choix multiples.
  • Python : if / elif / else / match...case.
