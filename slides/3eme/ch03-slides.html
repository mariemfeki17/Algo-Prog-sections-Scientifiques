Structures itératives

  Traitement

  Traitement
Fin Tant que

Répéter

Répéter
  Traitement

Choix de la structure

SituationStructure
Nombre connuPour
Test avantTant Que
Au moins 1 foisRépéter

Exemple Python

s = 0
n = int(input("n : "))
while n != 0:
    s = s + n
    n = int(input("n : "))
print("Somme =", s)

À retenir

  • Pour : nombre connu.
  • Tant Que : test avant.
  • Répéter : au moins 1 fois.
  • break interdit.
