Chapitre 04

Tableaux à une dimension

Définition

Regroupe plusieurs éléments de même type, accessibles par un indice.

Premier indice = 0.

Déclaration

Déclaration des objets
Objet       Type / Nature
T           Tableau de N Entier

Python — numpy

from numpy import array
T = array([0] * 10)
T2 = array([float()] * 10)
T3 = array([str] * 10)

Remplissage et affichage

n = int(input("Taille : "))
T = array([0] * n)
for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))
for i in range(n):
    print(T[i])

⚠ Interdit : print(T)

Exercice — Somme

Calculer la somme des éléments d'un tableau.

s = 0
for i in range(n):
    s = s + T[i]
print("Somme =", s)

À retenir

  • Indice de départ : 0.
  • Éléments de même type.
  • numpy : array.
  • Pas de print(T).
