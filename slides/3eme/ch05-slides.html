Chapitre 05

Modules : fonctions et procédures

Pourquoi modulariser ?

  • Lisibilité
  • Réutilisabilité
  • Maintenance
  • Testabilité

Fonction

Fonction Nom_fonction (pf1 : type1, …, pfN : typeN) : Type_résultat
DEBUT
  Traitement
  Retourner Résultat
FIN

Un seul résultat de type simple.

Procédure

Procédure Nom_procédure (pf1 : type1, …, pfN : typeN)
DEBUT
  Traitement
FIN

Passage

  • Par valeur : copie.
  • Par référence : symbole @.

Exemple — PGCD en Python

def pgcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

x = int(input("x : "))
y = int(input("y : "))
print("PGCD =", pgcd(x, y))

À retenir

  • Fonction = résultat.
  • Procédure = pas de résultat.
  • Python : def / return.
  • @ = passage par référence.
