Chapitre 07

Algorithmes numériques

PGCD — Euclide

Fonction PGCD (a, b) : Entier
DEBUT
  Tant que b ≠ 0 Faire
    r ← a Mod b
    a ← b
    b ← r
  Fin Tant que
  Retourner a
FIN

PPCM

PPCM(a, b) = (a * b) Div PGCD(a, b)

Primalité

Fonction EstPremier (n) : Booléen
DEBUT
  Si n < 2 Alors Retourner Faux FinSi
  i ← 2
  Tant que (i * i ≤ n) Et (n Mod i ≠ 0) Faire
    i ← i + 1
  Fin Tant que
  Retourner i * i > n
FIN

Implémentation Python

def pgcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

def est_premier(n):
    if n < 2: return False
    i = 2
    while i * i <= n and n % i != 0:
        i += 1
    return i * i > n

À retenir

  • PGCD : Euclide.
  • PPCM : (a × b) / PGCD.
  • Primalité : tester jusqu'à √n.
  • Facteurs premiers : division successive.
