Conditionnelles avancées

Conditionnelle généralisée

Si C1 Alors T1
Sinon Si C2 Alors T2
Sinon Si C3 Alors T3
Sinon TN
FinSi

Selon

Selon <Sélecteur>
  V1, V2 : T1
  V3 : T2
  Sinon TN
Fin Selon

Sélecteur scalaire.

Python — match...case

m = float(input("Moyenne : "))
match m:
    case m if 0 <= m < 10: print("Ajourné")
    case m if 10 <= m < 12: print("Passable")
    case m if 12 <= m < 14: print("Assez bien")
    case m if 14 <= m < 16: print("Bien")
    case m if 16 <= m <= 20: print("Très bien")
    case _: print("Moyenne invalide")

Choix de la structure

SituationStructure
Deux casSi...Sinon
Conditions ordonnéesSi...Sinon Si...
Valeurs précisesSelon
IntervallesSi généralisée

À retenir

  • Généralisée : conditions multiples.
  • Selon : sélecteur scalaire.
  • match...case : Python ≥ 3.10.
  • case _ : cas par défaut.
