Chapitre 06

La structure répétitive Pour

Structure

Pour Compteur de Début à Fin [Pas = valeur_pas] Faire
  Traitement
Fin Pour

Exemple — Somme des n premiers entiers

ALGORITHME SommeN
DEBUT
  Lire(n)
  s ← 0
  Pour i de 1 à n Faire
    s ← s + i
  Fin Pour
  Écrire("Somme = ", s)
FIN

Implémentation Python

n = int(input("n : "))
s = 0
for i in range(1, n + 1):
    s = s + i
print("Somme =", s)

Exercice — Factorielle

Calculer n! (factorielle de n).

ALGORITHME Factorielle
DEBUT
  Lire(n)
  f ← 1
  Pour i de 1 à n Faire
    f ← f * i
  Fin Pour
  Écrire("Factorielle = ", f)
FIN
