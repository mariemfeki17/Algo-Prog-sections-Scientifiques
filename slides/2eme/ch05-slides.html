Chapitre 05

La structure conditionnelle

Condition simple

Si Condition Alors
  Traitement
FinSi

Condition complète

Si Condition Alors
  Traitement1
Sinon
  Traitement2
FinSi

Opérateurs

  • Comparaison : =, ≠, >, ≥, <, ≤
  • Logiques : Non, Et, Ou

Exemple — Parité

ALGORITHME Parite
DEBUT
  Lire(n)
  Si n Mod 2 = 0 Alors
    Écrire("Pair")
  Sinon
    Écrire("Impair")
  FinSi
FIN

Implémentation Python

n = int(input("Entier : "))
if n % 2 == 0:
    print("Pair")
else:
    print("Impair")

Exercice — Maximum

Déterminer le maximum de deux entiers.

ALGORITHME Maximum
DEBUT
  Lire(a)
  Lire(b)
  Si a > b Alors
    Écrire("Max = ", a)
  Sinon
    Écrire("Max = ", b)
  FinSi
FIN

À retenir

  • Si...Alors : condition simple.
  • Si...Sinon : condition complète.
  • Python : if / else / elif.
  • Attention à == et l'indentation.
