Chapitre 03

Les types de données simples

Programme officiel 2022-2023 · Convention algorithmique 2024

Objectifs

  • Identifier les types : entier, réel, caractère, booléen, chaîne.
  • Choisir le type adéquat.
  • Implémenter et convertir en Python.

Les 5 types simples

  • Entier : 0, 5, -12
  • Réel : 3.14, -0.5
  • Caractère : 'A', '5'
  • Booléen : Vrai, Faux
  • Chaîne : "Bonjour"

Correspondances Python

  • Entier → int
  • Réel → float
  • Booléen → bool
  • Caractère / Chaîne → str

Conversions en Python

x = int("3")      # 3
y = float("3.2")  # 3.2
z = bool("0")     # True
s = str(123)      # "123"

Exemple — Fiche

nom = input("Nom : ")
age = int(input("Âge : "))
taille = float(input("Taille : "))
print("Nom :", nom)
print("Âge :", age)
print("Taille :", taille)

Pièges

  • input() renvoie une chaîne.
  • Caractère : apostrophes. Chaîne : guillemets.
  • / donne un réel, Div donne un entier.

À retenir

  • 5 types simples : entier, réel, caractère, booléen, chaîne.
  • Chaque objet a un type.
  • Python : int, float, bool, str.
