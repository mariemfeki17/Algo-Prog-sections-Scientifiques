Chapitre 02

Les objets : constantes et variables

Programme officiel 2022-2023 · Convention algorithmique 2024

Objectifs

  • Distinguer constante et variable.
  • Déclarer un objet selon la convention.
  • Affecter une valeur et implémenter en Python.

Objet

Une zone mémoire nommée dans laquelle on stocke une valeur.

→ Deux catégories : constantes et variables.

Constante vs Variable

Constante : valeur qui ne change pas.

Variable : valeur qui peut changer.

Déclaration des objets

ALGORITHME Nom_algorithme
DEBUT
  Traitements
FIN

Déclaration des objets
Objet          Type / Nature
Nom_objet      Type_objet

Affectation

Objet ← Expression

Le symbole ← se lit « reçoit ».

Exemple — Prix TTC

ALGORITHME PrixTTC
DEBUT
  Lire(prixHT)
  Lire(tauxTVA)
  prixTTC ← prixHT * (1 + tauxTVA / 100)
  Écrire("Prix TTC = ", prixTTC)
FIN

Déclaration des objets
Objet       Type / Nature
prixHT      Réel
tauxTVA     Réel
prixTTC     Réel

Implémentation Python

prixHT = float(input("Donner le prix HT : "))
tauxTVA = float(input("Donner le taux de TVA (%) : "))
prixTTC = prixHT * (1 + tauxTVA / 100)
print("Prix TTC =", prixTTC)

⚠ Python est sensible à la casse : Prix ≠ prix.

Pièges fréquents

  • Confondre constante et variable.
  • Noms non significatifs.
  • Oublier l'indentation.
  • Oublier la conversion après input().

Exercice — Périmètre d'un cercle

Calculer le périmètre d'un cercle de rayon R avec PI = 3.14.

ALGORITHME PerimetreCercle
DEBUT
  PI ← 3.14
  Lire(R)
  P ← 2 * PI * R
  Écrire("Périmètre = ", P)
FIN

Déclaration des objets
Objet    Type / Nature
PI       Réel (constante)
R        Réel
P        Réel

À retenir

  • Objet = constante ou variable.
  • Constante : valeur fixe. Variable : valeur modifiable.
  • Déclaration obligatoire dans l'algorithme.
  • Affectation : Objet ← Expression.
  • Python : pas de déclaration, sensible à la casse.
