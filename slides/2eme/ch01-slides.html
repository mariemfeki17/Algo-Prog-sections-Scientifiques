Chapitre 01

Notion de problème et d'algorithme

Programme officiel 2022-2023 · Convention algorithmique 2024

Objectifs du chapitre

  • Identifier les étapes de résolution d'un problème.
  • Dégager les entrées, les sorties et les traitements.
  • Écrire un algorithme simple selon la convention officielle.

Qu'est-ce qu'un algorithme ?

Une suite finie et ordonnée d'instructions permettant de résoudre un problème.

→ Indépendant de tout langage de programmation.

Forme générale

ALGORITHME Nom_algorithme
DEBUT
  Traitements
FIN

Déclaration des objets
Objet          Type / Nature
Nom_objet      Type_objet

Exemple — Somme de deux entiers

ALGORITHME Somme
DEBUT
  Lire(a)
  Lire(b)
  s ← a + b
  Écrire("La somme est : ", s)
FIN

Déclaration des objets
Objet    Type / Nature
a        Entier
b        Entier
s        Entier

Implémentation en Python

a = int(input("Donner le premier entier : "))
b = int(input("Donner le deuxième entier : "))
s = a + b
print("La somme est :", s)

⚠ input() renvoie une chaîne → conversion avec int() ou float().

Pièges fréquents

  • Oublier de déclarer les objets.
  • Négliger l'indentation.
  • Oublier la conversion de input().
  • Utiliser break (interdit).

Exercice — Aire d'un rectangle

Écrire un algorithme qui calcule et affiche l'aire d'un rectangle à partir de sa longueur et de sa largeur.

ALGORITHME AireRectangle
DEBUT
  Lire(L)
  Lire(l)
  A ← L * l
  Écrire("Aire = ", A)
FIN

Déclaration des objets
Objet    Type / Nature
L        Réel
l        Réel
A        Réel

À retenir

  • Algorithme = suite finie d'instructions.
  • Étapes : analyser → entrées → sorties → traitements → algorithme.
  • Respecter la convention algorithmique 2024.
  • Implémenter en Python avec input(), print(), =.
