Chapitre 04

Les opérations élémentaires

Lire — Entrée

Lire(Objet)

Saisir une valeur au clavier.

Écrire / Écrire_nl — Sortie

Écrire("Message", Objet, Expression)
Écrire_nl("Message", Objet, Expression)

Affectation

Objet ← Expression

Le symbole ← se lit « reçoit ».

Exemple — Moyenne

ALGORITHME Moyenne
DEBUT
  Lire(n1)
  Lire(n2)
  Lire(n3)
  m ← (n1 + n2 + n3) / 3
  Écrire("Moyenne = ", m)
FIN

Implémentation Python

n1 = float(input("Note 1 : "))
n2 = float(input("Note 2 : "))
n3 = float(input("Note 3 : "))
m = (n1 + n2 + n3) / 3
print("Moyenne =", m)

Pièges

  • Convertir après input().
  • Messages entre guillemets.
  • Interdit : print(T) pour un tableau.
