Chapitre 02 — Les structures conditionnelles : Si et Selon

1. Condition simple

Si Condition Alors
  Traitement
FinSi

2. Condition complète

Si Condition Alors
  Traitement1
Sinon
  Traitement2
FinSi

3. Condition généralisée

Si Condition1 Alors
  Traitement1
Sinon Si Condition2 Alors
  Traitement2
Sinon Si Condition3 Alors
  Traitement3
[Sinon
  TraitementN]
FinSi

4. Selon

Selon <Sélecteur>
  Valeur1_1[, Valeur1_2, …] : Traitement1
  Valeur2_1, Valeur2_2 : Traitement2
  [Sinon TraitementN]
Fin Selon

5. Correspondances Python

AlgorithmiquePython
Si...Alorsif ...:
Si...Sinonif ...: ... else: ...
Si...Sinon Si...if ...: ... elif ...: ... else: ...
Selonmatch...case

6. Exemple — Calculatrice

a = float(input("a : "))
b = float(input("b : "))
op = input("Opérateur : ")
match op:
    case '+': print("Somme =", a + b)
    case '-': print("Différence =", a - b)
    case '*': print("Produit =", a * b)
    case '/':
        if b != 0: print("Quotient =", a / b)
        else: print("Division par zéro impossible")
    case _: print("Opérateur inconnu")

7. Pièges

  • Sélecteur de Selon : scalaire uniquement.
  • match...case : Python ≥ 3.10.
  • Ne pas oublier Sinon / case _.
  • Attention à = et ==.
