Chapitre 08 — Robotique — Consolidation

1. Rappels

  • Domaines : industrie, médecine, agriculture, espace, éducation.
  • Programmation : Micro-Python / Arduino.

2. Feu de carrefour complet

from microbit import *
while True:
    pin0.write_digital(1); pin1.write_digital(0); pin2.write_digital(0)
    sleep(3000)  # Rouge
    pin0.write_digital(0); pin1.write_digital(1); pin2.write_digital(0)
    sleep(1000)  # Orange
    pin0.write_digital(0); pin1.write_digital(0); pin2.write_digital(1)
    sleep(3000)  # Vert
    pin0.write_digital(0); pin1.write_digital(1); pin2.write_digital(0)
    sleep(1000)  # Orange

3. Factorisation avec module

from microbit import *

def allumer(rouge, orange, vert):
    pin0.write_digital(rouge)
    pin1.write_digital(orange)
    pin2.write_digital(vert)

while True:
    allumer(1, 0, 0); sleep(3000)
    allumer(0, 1, 0); sleep(1000)
    allumer(0, 0, 1); sleep(3000)
    allumer(0, 1, 0); sleep(1000)

4. Remarques

  • Pas d'application complète.
  • Micro-Python / Arduino.
  • Factoriser avec des modules.
