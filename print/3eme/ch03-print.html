4. Exemple — Somme jusqu'à 0

ALGORITHME SommeZero
DEBUT
  s ← 0
  Lire(n)
  Tant que n ≠ 0 Faire
    s ← s + n
    Lire(n)
  Fin Tant que
  Écrire("Somme = ", s)
FIN

Déclaration des objets
Objet    Type / Nature
n        Entier
s        Entier

5. Implémentation Python

s = 0
n = int(input("n : "))
while n != 0:
    s = s + n
    n = int(input("n : "))
print("Somme =", s)

6. Pièges

  • Boucle infinie si la condition ne change pas.
  • Ne pas modifier le compteur dans Pour.
  • break interdit.
