Chapitre 06 — Traitements sur tableaux : recherche et tri à bulles

1. Recherche d'un élément

Fonction Recherche (T : Tableau de 100 Entier, n : Entier, x : Entier) : Entier
DEBUT
  i ← 0
  pos ← -1
  Tant que (i < n) Et (pos = -1) Faire
    Si T[i] = x Alors
      pos ← i
    Sinon
      i ← i + 1
    FinSi
  Fin Tant que
  Retourner pos
FIN

2. Tri à bulles

Procédure TriBulles (@T : Tableau de 100 Entier, n : Entier)
DEBUT
  Pour i de 1 à n - 1 Faire
    Pour j de 0 à n - i - 1 Faire
      Si T[j] > T[j + 1] Alors
        aux ← T[j]
        T[j] ← T[j + 1]
        T[j + 1] ← aux
      FinSi
    Fin Pour
  Fin Pour
FIN

3. Implémentation Python

def recherche(T, n, x):
    i = 0
    pos = -1
    while i < n and pos == -1:
        if T[i] == x:
            pos = i
        else:
            i = i + 1
    return pos

def tri_bulles(T, n):
    for i in range(1, n):
        for j in range(n - i):
            if T[j] > T[j + 1]:
                T[j], T[j + 1] = T[j + 1], T[j]

4. Pièges

  • Bornes des boucles : n - i - 1.
  • Variable temporaire pour l'échange.
  • Pas de break.
