Chapitre 04 — Les tableaux à une dimension

1. Définition

Un tableau à une dimension regroupe plusieurs éléments de même type, accessibles par un indice.

Indice du premier élément : 0.

2. Déclaration en algorithmique

Déclaration des objets
Objet       Type / Nature
T           Tableau de N Entier

3. Déclaration en Python (numpy)

from numpy import array

T = array([0] * 10)          # 10 entiers à 0
T = array([float()] * 10)    # 10 réels à 0.0
T = array([str] * 10)        # 10 chaînes
T = array([str()] * 10)      # 10 caractères vides
T = array([''] * 10, dtype='U20')  # 10 chaînes de 20 caractères

4. Parcours

ALGORITHME RemplirAfficher
DEBUT
  Lire(n)
  Pour i de 0 à n - 1 Faire
    Lire(T[i])
  Fin Pour
  Pour i de 0 à n - 1 Faire
    Écrire(T[i])
  Fin Pour
FIN

Déclaration des objets
Objet    Type / Nature
T        Tableau de 100 Entier
n        Entier
i        Entier

5. Implémentation Python

from numpy import array
n = int(input("Taille : "))
T = array([0] * n)
for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))
for i in range(n):
    print(T[i])

Interdit : print(T).
