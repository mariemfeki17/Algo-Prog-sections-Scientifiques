Chapitre 05 — Les modules : fonctions et procédures

1. Pourquoi modulariser ?

  • Lisibilité, réutilisabilité, maintenance, testabilité.

2. Fonction

Fonction Nom_fonction (pf1 : type1, …, pfN : typeN) : Type_résultat
DEBUT
  Traitement
  Retourner Résultat
FIN

Une fonction retourne un seul résultat de type simple.

3. Procédure

Procédure Nom_procédure (pf1 : type1, …, pfN : typeN)
DEBUT
  Traitement
FIN

4. Appel et passage

ModuleAppel
FonctionObjet ← Nom_fonction(pe1, …, peN)
ProcédureNom_procédure(pe1, …, peN)

Passage par référence : symbole @ avant le paramètre.

5. Exemple — PGCD

Fonction PGCD (a : Entier, b : Entier) : Entier
DEBUT
  Tant que b ≠ 0 Faire
    r ← a Mod b
    a ← b
    b ← r
  Fin Tant que
  Retourner a
FIN

6. Implémentation Python

def pgcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

x = int(input("x : "))
y = int(input("y : "))
p = pgcd(x, y)
print("PGCD =", p)
