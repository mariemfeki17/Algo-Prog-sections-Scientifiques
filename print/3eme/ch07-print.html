Chapitre 07 — Algorithmes numériques

1. PGCD — Euclide

Fonction PGCD (a : Entier, b : Entier) : Entier
DEBUT
  Tant que b ≠ 0 Faire
    r ← a Mod b
    a ← b
    b ← r
  Fin Tant que
  Retourner a
FIN

2. PPCM

Fonction PPCM (a : Entier, b : Entier) : Entier
DEBUT
  Retourner (a * b) Div PGCD(a, b)
FIN

Relation : PGCD × PPCM = a × b.

3. Primalité

Fonction EstPremier (n : Entier) : Booléen
DEBUT
  Si n < 2 Alors
    Retourner Faux
  FinSi
  i ← 2
  Tant que (i * i ≤ n) Et (n Mod i ≠ 0) Faire
    i ← i + 1
  Fin Tant que
  Retourner i * i > n
FIN

4. Décomposition en facteurs premiers

Procédure FacteursPremiers (n : Entier)
DEBUT
  d ← 2
  Tant que n > 1 Faire
    Tant que n Mod d = 0 Faire
      Écrire(d)
      n ← n Div d
    Fin Tant que
    d ← d + 1
  Fin Tant que
FIN

5. Implémentation Python

def pgcd(a, b):
    while b != 0:
        r = a % b
        a = b
        b = r
    return a

def ppcm(a, b):
    return (a * b) // pgcd(a, b)

def est_premier(n):
    if n < 2:
        return False
    i = 2
    while i * i <= n and n % i != 0:
        i = i + 1
    return i * i > n

6. Pièges

  • Primalité : tester jusqu'à √n.
  • PPCM : division entière Div.
  • 1 n'est pas premier.
