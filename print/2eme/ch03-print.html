Déclaration des objets
Objet    Type / Nature
nom      Chaîne de caractères
age      Entier
taille   Réel
nom = input("Nom : ")
age = int(input("Âge : "))
taille = float(input("Taille : "))
print("Nom :", nom)
print("Âge :", age)
print("Taille :", taille)

6. Remarques et pièges

  • input() renvoie toujours une chaîne.
  • Caractère entre apostrophes, chaîne entre guillemets.
  • / donne un réel, Div donne un entier.
