Chapitre 04 — Les opérations élémentaires

1. Les trois opérations

Entrée — Lire

Lire(Objet)

Sortie — Écrire / Écrire_nl

Écrire("Message", Objet, Expression)
Écrire_nl("Message", Objet, Expression)

Affectation

Objet ← Expression

2. Correspondances Python

AlgorithmiquePython
Lire(a)a = int(input())
Écrire("…", x)print("…", x)
Écrire_nl("…", x)print("…", x, "\n")
a ← b + ca = b + c

3. Exemple — Moyenne

ALGORITHME Moyenne
DEBUT
  Lire(n1)
  Lire(n2)
  Lire(n3)
  m ← (n1 + n2 + n3) / 3
  Écrire("Moyenne = ", m)
FIN

Déclaration des objets
Objet        Type / Nature
n1, n2, n3   Réel
m            Réel

4. Implémentation Python

n1 = float(input("Note 1 : "))
n2 = float(input("Note 2 : "))
n3 = float(input("Note 3 : "))
m = (n1 + n2 + n3) / 3
print("Moyenne =", m)

5. Pièges

  • Convertir après input().
  • Messages entre guillemets.
  • Ne pas confondre Écrire et Écrire_nl.
  • En algorithmique : ← et non =.
