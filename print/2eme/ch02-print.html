Chapitre 02 — Les objets : constantes et variables

Conforme aux Aides pédagogiques 2022-2023 · Convention algorithmique 2024 · Convention d'implémentation 2024-2025

1. Références officielles

DomainePensée computationnelle et programmation

2. Définitions

Objet

Zone mémoire nommée dans laquelle on stocke une valeur. On distingue les constantes et les variables.

Constante

Objet dont la valeur ne change pas pendant l'exécution de l'algorithme.

Variable

Objet dont la valeur peut changer au cours de l'exécution de l'algorithme.

3. Déclaration des objets

ALGORITHME Nom_algorithme
DEBUT
  Traitements
FIN

Déclaration des objets
Objet          Type / Nature
Nom_objet      Type_objet

Règles : nomenclature significative, indentation respectée, chaque objet a un type.

4. Affectation

Objet ← Expression

Le symbole ← se lit « reçoit ».

5. Exemple — Prix TTC

ALGORITHME PrixTTC
DEBUT
  Lire(prixHT)
  Lire(tauxTVA)
  prixTTC ← prixHT * (1 + tauxTVA / 100)
  Écrire("Prix TTC = ", prixTTC)
FIN

Déclaration des objets
Objet       Type / Nature
prixHT      Réel
tauxTVA     Réel
prixTTC     Réel

6. Implémentation en Python

prixHT = float(input("Donner le prix HT : "))
tauxTVA = float(input("Donner le taux de TVA (%) : "))
prixTTC = prixHT * (1 + tauxTVA / 100)
print("Prix TTC =", prixTTC)

Rappel : en Python, une variable est créée au moment de l'affectation. Le langage est sensible à la casse.

7. Remarques et pièges fréquents

  • Ne pas confondre constante et variable.
  • Utiliser des noms significatifs.
  • Respecter l'indentation.
  • Convertir après input().
  • Pas d'espaces ni de chiffre en début de nom de variable.

8. Exercices

Exercice 1 — Périmètre d'un cercle

Calculer le périmètre d'un cercle de rayon R avec PI = 3.14.

Correction :

ALGORITHME PerimetreCercle
DEBUT
  PI ← 3.14
  Lire(R)
  P ← 2 * PI * R
  Écrire("Périmètre = ", P)
FIN

Déclaration des objets
Objet    Type / Nature
PI       Réel (constante)
R        Réel
P        Réel

Exercice 2 — Échange de deux variables

Échanger les valeurs de a et b.

Correction :

ALGORITHME Echange
DEBUT
  Lire(a)
  Lire(b)
  aux ← a
  a ← b
  b ← aux
  Écrire("a = ", a, " b = ", b)
FIN

Déclaration des objets
Objet    Type / Nature
a        Entier
b        Entier
aux      Entier
