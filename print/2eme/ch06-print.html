Chapitre 06 — La structure répétitive Pour

1. Structure

Pour Compteur de Début à Fin [Pas = valeur_pas] Faire
  Traitement
Fin Pour

Pas par défaut : 1. Ne jamais modifier le compteur dans le traitement.

2. Exemple — Somme des n premiers entiers

ALGORITHME SommeN
DEBUT
  Lire(n)
  s ← 0
  Pour i de 1 à n Faire
    s ← s + i
  Fin Pour
  Écrire("Somme = ", s)
FIN

Déclaration des objets
Objet    Type / Nature
n        Entier
i        Entier
s        Entier

3. Implémentation Python

n = int(input("n : "))
s = 0
for i in range(1, n + 1):
    s = s + i
print("Somme =", s)

Attention : range(D, F+1) inclut F ; range(D, F) l'exclut.

4. Pièges

  • Oublier le +1 dans range.
  • Ne pas initialiser l'accumulateur.
  • Modifier le compteur dans la boucle.
  • Utiliser break (interdit).
