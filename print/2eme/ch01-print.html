2. Définitions

Problème

Situation pour laquelle on cherche une solution : entrées → traitements → sorties.

Algorithme

Suite finie et ordonnée d'instructions permettant de résoudre un problème, indépendante de tout langage.

3. Forme générale d'un algorithme

ALGORITHME Nom_algorithme
DEBUT
  Traitements
FIN

Déclaration des objets
Objet          Type / Nature
Nom_objet      Type_objet

4. Exemple — Somme de deux entiers

ALGORITHME Somme
DEBUT
  Lire(a)
  Lire(b)
  s ← a + b
  Écrire("La somme est : ", s)
FIN

Déclaration des objets
Objet    Type / Nature
a        Entier
b        Entier
s        Entier

5. Implémentation en Python

a = int(input("Donner le premier entier : "))
b = int(input("Donner le deuxième entier : "))
s = a + b
print("La somme est :", s)

6. Remarques et pièges fréquents

  • Déclarer tous les objets.
  • Respecter l'indentation.
  • En Python, input() renvoie une chaîne : convertir avec int() ou float().
  • Nomenclature significative.
  • Ne jamais utiliser break.

7. Exercices

Exercice 1 — Aire d'un rectangle

Écrire un algorithme qui calcule et affiche l'aire d'un rectangle.

Correction :

ALGORITHME AireRectangle
DEBUT
  Lire(L)
  Lire(l)
  A ← L * l
  Écrire("Aire = ", A)
FIN

Déclaration des objets
Objet    Type / Nature
L        Réel
l        Réel
A        Réel

Exercice 2 — Moyenne de trois notes

Écrire un algorithme qui calcule la moyenne de trois notes.

Correction :

ALGORITHME Moyenne
DEBUT
  Lire(n1)
  Lire(n2)
  Lire(n3)
  m ← (n1 + n2 + n3) / 3
  Écrire("Moyenne = ", m)
FIN

Déclaration des objets
Objet        Type / Nature
n1, n2, n3   Réel
m            Réel
