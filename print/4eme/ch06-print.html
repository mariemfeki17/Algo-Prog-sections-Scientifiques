3. Python — Fichier données (pickle)

from pickle import dump, load

F = open('donnees.dat', 'wb')
dump(42, F)
dump("Bonjour", F)
F.close()

F = open('donnees.dat', 'rb')
fini = False
while not fini:
    try:
        x = load(F)
        print(x)
    except:
        fini = True
F.close()

4. Python — Fichier texte

F = open('notes.txt', 'w')
F.write("Ali\n")
F.write("Sami\n")
F.close()

F = open('notes.txt', 'r')
ch = F.readline()
while ch != "":
    print(ch.strip())
    ch = F.readline()
F.close()

5. Pièges

  • Toujours close().
  • Modes rb/wb/ab (données) vs r/w/a (textes).
  • Fin fichier texte : chaîne vide.
  • try/except pour pickle.
