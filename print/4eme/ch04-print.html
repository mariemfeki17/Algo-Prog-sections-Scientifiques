Chapitre 04 — Tri : sélection et insertion

1. Tri par sélection

Procédure TriSelection (@T : Tableau de 100 Entier, n : Entier)
DEBUT
  Pour i de 0 à n - 2 Faire
    min ← i
    Pour j de i + 1 à n - 1 Faire
      Si T[j] < T[min] Alors min ← j FinSi
    Fin Pour
    Si min ≠ i Alors
      aux ← T[i]; T[i] ← T[min]; T[min] ← aux
    FinSi
  Fin Pour
FIN

2. Tri par insertion

Procédure TriInsertion (@T : Tableau de 100 Entier, n : Entier)
DEBUT
  Pour i de 1 à n - 1 Faire
    cle ← T[i]
    j ← i - 1
    Tant que (j ≥ 0) Et (T[j] > cle) Faire
      T[j + 1] ← T[j]
      j ← j - 1
    Fin Tant que
    T[j + 1] ← cle
  Fin Pour
FIN

3. Comparaison

CritèreSélectionInsertion
ComplexitéO(n²)O(n²)
ÉchangesPeuBeaucoup

4. Implémentation Python

def tri_selection(T, n):
    for i in range(n - 1):
        mini = i
        for j in range(i + 1, n):
            if T[j] < T[mini]:
                mini = j
        if mini != i:
            T[i], T[mini] = T[mini], T[i]

def tri_insertion(T, n):
    for i in range(1, n):
        cle = T[i]
        j = i - 1
        while j >= 0 and T[j] > cle:
            T[j + 1] = T[j]
            j = j - 1
        T[j + 1] = cle

5. Pièges

  • Bornes : n-1, i+1.
  • Tri insertion : j ≥ 0.
  • Variable temporaire pour l'échange.
  • Pas de break.
