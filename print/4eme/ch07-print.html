Chapitre 07 — Interface graphique avec Qt Designer

1. Principes

  • GUI : interaction via objets visuels.
  • Qt Designer : glisser-déposer.
  • Sauvegarde dans un fichier .ui.

2. Objets graphiques

ObjetRôle
QLabelÉtiquette
QLineEditChamp de saisie
QPushButtonBouton
QTextEditTexte multilignes

3. Méthodes autorisées

  • .text
  • .setText(...)
  • .clear()
  • .show()
  • .clicked

4. Exemple — Calculatrice simple

from PyQt5.QtWidgets import QApplication, QMainWindow
from PyQt5.uic import loadUi
import sys

class Fenetre(QMainWindow):
    def __init__(self):
        super().__init__()
        loadUi("calculatrice.ui", self)
        self.btnSomme.clicked.connect(self.calculer)

    def calculer(self):
        a = float(self.txtA.text)
        b = float(self.txtB.text)
        self.lblResultat.setText("Somme = " + str(a + b))

app = QApplication(sys.argv)
f = Fenetre()
f.show()
app.exec_()

5. Pièges

  • Se limiter aux méthodes listées.
  • Une seule interface.
  • GUI = amélioration ergonomique.
