Chapitre 08 — Programmation événementielle

1. Principe

Réagir à des événements (clic, saisie...) déclenchés par l'utilisateur.

2. Connexion d'un événement

self.btnValider.clicked.connect(self.valider)

3. Exemple complet

from PyQt5.QtWidgets import QApplication, QMainWindow
from PyQt5.uic import loadUi
import sys

class Fenetre(QMainWindow):
    def __init__(self):
        super().__init__()
        loadUi("calculatrice.ui", self)
        self.btnSomme.clicked.connect(self.calculer)
        self.btnEffacer.clicked.connect(self.effacer)

    def calculer(self):
        try:
            a = float(self.txtA.text)
            b = float(self.txtB.text)
            self.lblResultat.setText("Somme = " + str(a + b))
        except:
            self.lblResultat.setText("Saisie invalide")

    def effacer(self):
        self.txtA.clear()
        self.txtB.clear()
        self.lblResultat.clear()

app = QApplication(sys.argv)
f = Fenetre()
f.show()
app.exec_()

4. Ergonomie

  • Réinitialiser les champs.
  • Vérifier les saisies avec try/except.
  • Messages clairs.
