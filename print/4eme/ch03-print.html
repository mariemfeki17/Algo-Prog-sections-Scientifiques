4. Exemple — Recherche

from numpy import array
n = int(input("Taille : "))
T = array([0] * n)
for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))
x = int(input("x : "))
pos = -1
i = 0
while i < n and pos == -1:
    if T[i] == x:
        pos = i
    i = i + 1
print("Position =", pos)

5. Pièges

  • Boucle infinie si condition immuable.
  • Pas de break.
  • Ne pas modifier le compteur d'un Pour.
