Chapitre 05 — Modules et décomposition en sous-problèmes

1. Décomposition en sous-problèmes

  1. Analyser l'énoncé.
  2. Regrouper les tâches en modules.
  3. Définir l'entête de chaque module.
  4. Écrire chaque module.

  6. Assembler.

2. Éléments d'un module

ÉlémentDescription
EntêteNom + paramètres + type de retour
ParamètresPar valeur ou référence
RésultatUn seul, simple (fonction)
PortéeLocale ou globale
AppelUtilisation du module

3. Exemple — Moyenne et Maximum

Fonction SommeTab (T : Tableau de 100 Entier, n : Entier) : Entier
DEBUT
  s ← 0
  Pour i de 0 à n - 1 Faire
    s ← s + T[i]
  Fin Pour
  Retourner s
FIN

Fonction MaximumTab (T : Tableau de 100 Entier, n : Entier) : Entier
DEBUT
  max ← T[0]
  Pour i de 1 à n - 1 Faire
    Si T[i] > max Alors max ← T[i] FinSi
  Fin Pour
  Retourner max
FIN

4. Implémentation Python

def somme_tab(T, n):
    s = 0
    for i in range(n):
        s = s + T[i]
    return s

def maximum_tab(T, n):
    maxi = T[0]
    for i in range(1, n):
        if T[i] > maxi:
            maxi = T[i]
    return maxi

n = int(input("Taille : "))
T = array([0] * n)
for i in range(n):
    T[i] = int(input("T[" + str(i) + "] : "))
print("Moyenne =", somme_tab(T, n) / n)
print("Maximum =", maximum_tab(T, n))

5. Bonnes pratiques
